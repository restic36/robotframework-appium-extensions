# Contribuição

Todas as tarefas devem ser desenvolvidas em branches do tipo `feature/keyword-*`.

Faça commits frequentes com mensagens claras e objetivas.

Após finalizar sua tarefa, abra um Pull Request para a branch `develop`.

**Padrão de commit:**

- feat: implementação de funcionalidade
- fix: correção
- docs: documentação
- test: testes
